# tak

Your Pinterest board, laid out across your Windows desktop. Paste a public board, and tak builds a fresh wallpaper from it every half hour.

**Download:** [somethinghaus.com/tak](https://somethinghaus.com/tak/) or the latest file under [Releases](https://github.com/somethinghaus/tak/releases/latest).

Windows 10 and 11. 7-day free trial, then a lifetime licence for up to 3 PCs. macOS coming soon.
